AI-powered spot the difference image generation & dataset creation

AI Engineer | Python Developer | Dataset Generation Specialist

A large-scale project that generated approximately 1 million images for visual puzzles, using AI tools and Python pipelines to create image pairs with subtle, controlled differences.

The challenge

Puzzle content needs a constant supply of image pairs that look identical at first glance but contain a set number of clear, fair differences. Creating these by hand does not scale, and naive AI generation produces inconsistent pairs.

The solution

I built Python-based generation pipelines that create a base scene, apply controlled edits (object changes, color variations, additions and removals), and track every difference, with automated error tracking and quality checks so the output stays consistent across a very large volume.

How it works

  1. Scene generationPrompt-engineered base scenes with a consistent style.
  2. Controlled editsObject changes, color variations, additions and removals applied to create the second image.
  3. Difference trackingEach difference is recorded so answers can be shown and verified.
  4. Quality checksAutomated error tracking and review to catch broken or unfair pairs.
  5. Dataset organizationPairs, metadata and answers organized for scalable content production.

Key features

  • Approximately 1 million images generated
  • Subtle, controlled differences per pair
  • Python pipeline with error tracking
  • Focus on visual consistency and quality
  • Organized dataset structure with metadata

Results

  • A very large, consistent library of puzzle-ready image pairs
  • Repeatable pipeline that scales content production
  • Experience building and quality-checking AI datasets at volume

This project is closely related to my data annotation and AI training data work: generating, labeling and quality-checking images at scale.
