Excel-to-GIS infrastructure asset map with AI data checks & plain-English search

GIS & Automation Developer | ArcGIS, Python & AI

A public works team managed thousands of assets in Excel, spread across workbooks that each crew laid out its own way. I turned those spreadsheets into one live, searchable map without asking anyone to stop using Excel.

The challenge

The team’s asset records lived in Excel: one workbook for hydrants, another for valves, separate ones for each area’s water mains, pump stations and streetlights. Each crew used its own headers, some rows had coordinates and others only a street address, and dates and condition scores were typed in different ways. To answer a simple question like “which old mains near overdue hydrants need attention?”, someone had to open several files and piece the answer together by hand. Moving everything into a new system was not an option, because the crews were comfortable with Excel and kept it up to date.

The solution

I kept Excel as the place where data is edited and built everything else around it. A sync job notices when a workbook is saved, uses AI to match its columns to one shared asset schema, checks every row, finds a location for rows without coordinates and pushes only the changed rows to ArcGIS hosted feature layers. On top sits a web map where staff can switch layers, filter, search, click any asset for its details, ask questions in plain English and export results back to Excel. A dashboard shows condition and inspection status for whatever area is on screen.

How it works

  1. Watch the workbooksn8n listens for changes to the registers on SharePoint and OneDrive through Microsoft Graph, and a nightly run re-checks every file in full.
  2. Map the columns with AIThe Claude API reads each sheet’s headers and a few sample rows and maps them to the shared schema with a confidence score. High-confidence matches are saved per workbook; anything uncertain is sent to the sheet owner to confirm once.
  3. Check every rowpandas and Pydantic check asset IDs, duplicates, dates, condition scores and coordinate ranges. Simple problems such as dates typed as text are fixed automatically, and anything else is held back with the exact row and reason.
  4. Find each locationRows with coordinates are converted from the local grid with pyproj. Rows with only an address or a street intersection are geocoded with the ArcGIS geocoding service, and the result is cached.
  5. Publish only the changesThe ArcGIS API for Python compares each row with the feature layer and adds, updates or retires only what changed, one layer per asset type.
  6. Keep a historyEvery sync is logged in PostgreSQL with the workbook, row, old and new values, so any change on the map can be traced back to the spreadsheet.
  7. View and askA web app built with the ArcGIS Maps SDK for JavaScript offers layer toggles, filters, search, clustering, popups and export. Plain-English questions are turned into layer filters by the Claude API and checked against a list of allowed fields before they run.

Technical challenges and how they were solved

  • Nine different sheet layouts: AI column mapping saved per workbook, so it only runs again when headers change
  • Missing or mixed coordinates: grid conversion where coordinates exist, geocoding with caching where they do not
  • Bad rows reaching the map: row checks that hold a record back instead of publishing it, with the reason sent to its owner
  • Slow full reloads: change-only updates, so a normal save reaches the map in under a minute
  • Unsafe AI queries: generated filters are limited to known fields and operators and are never run as free SQL

Results

  • About 18,400 assets across five asset types on one map, updated within a minute of a spreadsheet save
  • Around 2,900 assets that only had an address now have a location
  • Duplicate IDs and impossible dates are caught before they reach the map, not months later
  • Questions that took an afternoon of spreadsheet work are answered in seconds on the map
  • Crews still edit in Excel, so there was no new tool to learn and no data entry twice
