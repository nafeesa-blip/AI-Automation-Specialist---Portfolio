The challenge

Payroll data lived in Google Sheets, and every pay period someone had to copy attendance, overtime, allowances and deductions into freee HR by hand. It was slow and a single typo could mean a wrong salary.

The solution

I built an Apps Script automation that processes and maps the payroll data inside Google Sheets and sends it to freee HR through its REST API, from a custom menu with a Send button and a clear status dialog.

How it works

  1. Collect dataAttendance, overtime and night shift data is read from the sheet.
  2. Process payroll itemsSalary, allowances, transport expenses and deductions are calculated.
  3. Map and formatData is mapped and formatted to match the freee HR API.
  4. ReviewThe user reviews everything before sending.
  5. Send to freee HRA custom Send button pushes the data via REST API and shows each processing step and the result.

Key features

  • Extracts attendance, overtime and night shift data
  • Processes salary, allowances, transport expenses and deductions
  • Automates data mapping and formatting in Google Sheets
  • Integrates freee HR using REST APIs
  • Custom Send button for easy data submission
  • Manual review before payroll data is sent

Results

  • Payroll data moves in minutes instead of hours
  • Fewer data entry errors
  • A simple button anyone on the team can use
